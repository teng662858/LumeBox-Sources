# 补齐内容分类

独播库 1.0.1、蝴蝶影院 1.0.2 声明 `contentCategory: movie`；ASMR 吧 1.0.1、蜜糖助眠 1.0.2 声明 `contentCategory: adult`。两处版本声明同步，列表、详情和播放逻辑不变。

ASMR 吧首页明确标示成人向助眠入口，蜜糖助眠首页有 18+ 成人 ASMR 提示，因此同步补入分级表。未知来源仍不凭名字或版本号标成人。悦听原本已经声明 `category: audiobook`，目录生成器现在正确将它放入有声清单。

`video` 是 App 板块，不能代替内容分类。发布清单时，新视频源若既没有 movie/adult 声明，也没有已核实的成人分级，会被生成器拒绝，避免写好的源继续进入“待分类”。漫画和有声来源保持各自分类。

验证：四个脚本的 Node 语法检查、目录生成一致性，以及 `python -m unittest discover -s tools -p test_source_classifications.py -v`。GitHub/CDN 版本、内容分类及最新快照需在发布后实际下载核对。
