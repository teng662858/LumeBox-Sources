# 注视影视 1.0.2

源 ID：`gaze_video`，归入影视订阅。支持首页作品、电影/剧集/动漫/国漫分类、关键词搜索、排序、网页按钮分页、详情和默认线路选集。播放使用源站网页播放器，需要支持 `LumeSource.web.episodeSelection` 的新版 LumeBox；旧版会提示升级。

站点详情是 `/play/<32位标识>`。选集由 `.playbtn[data-id]` 按钮触发，点击后页面地址不变。源返回作品地址和指定按钮选择器；App 页面加载后点击指定集数。`blob:` 地址及短期媒体签名不作为可复用直链，Cookie、登录态、播放器签名和媒体内容不随源发布。
